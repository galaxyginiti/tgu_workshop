# Занятие 6: итог за одну неделю

**7 ноября — выдача объединённых этапов 6 и 7. К началу занятия 14 ноября — законченный комплект и презентация.** Новые исходные данные не выдаются.

Начните с `Задание_занятие_6.md`; `Вводная_от_заказчика.md` объясняет ожидаемый результат.

Три результата сдачи: проект с кодом и сохранённой моделью; короткий README внутри проекта; готовая презентация на 8–12 слайдов в одном удобном для показа формате.

## Шаблоны

- `Шаблон_README.md` — единый документ с запуском, результатами и выводом.
- `Протокол_итоговой_проверки.md` — пять строк для вставки в README; отдельно не сдаётся.
- `Шаблон_защиты.md` — восемь базовых слайдов, можно расширить до двенадцати. Защита: 12 минут выступление + 3 минуты вопросы; всего 15 минут на команду.

Отдельный отчёт, техническая/пользовательская инструкция и чек-лист не требуются.

## Стартовый код

`starter/evaluation_start.ipynb` помогает загрузить модель этапа 5 и выполнить итоговое сравнение без обучения. Укажите свои пути к прежним признакам и модели. Сохраните рядом модули преобразований, необходимые вашему Pipeline.

`campaign_metrics.py` и `evaluation_utils.py` содержат готовые расчёты. Дополнительные функции сегментного анализа и permutation importance можно пропустить: они не увеличивают обязательный объём. `preprocessing_template.py` нужен для совместимой загрузки модели, если использовали этот модуль на этапе 5.

Обязательны три проверки из задания: общая база и K; сохранённая модель без обучения/подбора на test; повторный запуск той же версии. Повтор допустим в текущем окружении и тем же участником. В README достаточно одной строки результата.

Перед показом test заполните короткий протокол. Если test уже использовали для выбора модели, честно отметьте это в README.

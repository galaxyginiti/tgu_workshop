## Решение команды

Командный проект «Прогнозирование оттока абонентов» (этапы 1–4) находится в папке [`solution/`](solution/README.md). Исходные материалы курса в папках `1_introduction/` … `4_features/` не изменены.

```bash
pip install -r solution/requirements.txt
python solution/run_all.py
```

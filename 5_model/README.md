# Комплект занятия 5: построение и обучение модели

Занятие: **31 октября 2026**. Сдача: **к началу занятия 7 ноября 2026**.

Новых исходных данных в комплекте нет. Работайте с собственными результатами четвёртого этапа.

| Файл | Назначение |
|---|---|
| Вводная_от_заказчика.md | Ожидаемый результат и сохранённые ограничения |
| Задание_занятие_5.md | Порядок работы и критерии сдачи |
| Журнал_экспериментов_шаблон.md | Шаблон сравнения запусков |
| Шаблон_отчёта_обучение.md | Структура короткого отчёта |

| starter/check_saved_model.py | Повторная загрузка собственного Pipeline без fit |

**Перед запуском измените списки признаков в config_example.json на собственные.** В нём приведены имена из преподавательского примера этапа 4. Имя `baseline_feature` также должно соответствовать столбцу прошлого долга в вашей таблице. Не создавайте пустые столбцы для подгонки под пример.

Распакуйте комплект в `lesson5`. Откройте ноутбук из `lesson5/starter` и задайте `PREPARED` — папку со своими `features.csv`, `labels.csv`, `split.csv`. Исходные пропуски в CSV представлены пустыми полями, числа используют точку, разделитель `;`, кодировка UTF-8 с BOM. Ключи должны иметь одно и то же каноническое строковое представление во всех трёх таблицах.

Для примеров нужны Python, numpy, pandas, scikit-learn, joblib и Jupyter. Сохраните свои фактические версии. Готовый пример преподавателя проверяется в отдельной среде, её версии приведены в преподавательском комплекте. Если команда использует другие реализации выбранных методов, зафиксируйте дополнительные зависимости.

Ноутбук показывает первый опыт. Полный цикл двух методов, сравнение, журнал, выбор и сохранение выполняет команда. Вспомогательные модули нужно сохранять рядом с кодом загрузки Pipeline, поскольку сохранённый объект использует функцию из preprocessing_template.py.
